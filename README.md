# ITパス道場（itpass）

ITパスポート試験の合格を目指す iOS 学習アプリです。飽きずに続けられるよう、いくつもの学び方を用意しています。

## 収録データ

- **オリジナル問題 490問**（ストラテジ189・マネジメント70・テクノロジ231）全問に解説つき
- **誤答1,470個すべてに「なぜ違うか」の解説**（その選択肢が何を指す用語なのか、計算のどこを間違えたのかなど）
- **用語 369語**（フラッシュカード・ゲーム・用語辞典で使用）
- シラバスの全22分野をカバー。生成AI・LLM・ゼロトラストなど新しい用語も収録

## 学び方

| モード | 内容 |
|---|---|
| 今日のトレーニング | 復習どき・苦手・新しい問題を自動で10問にミックス |
| 分野別ドリル | 分野を選んで5〜30問。未回答と苦手を優先 |
| 苦手克服 / 復習 / ブックマーク | 間違えた問題、間隔反復で復習どきの問題、保存した問題 |
| タイムアタック | 60秒で説明に合う用語を4択で選び続ける。5連続で+3秒 |
| サバイバル | ライフ3つ。本番形式の問題が徐々に難しくなる |
| ○×スピード | 用語と説明の組合せが正しいかを45秒でスワイプ判定 |
| 用語マッチ | 6組の用語と説明を最速でつなげる |
| フラッシュカード | めくって覚える。1日→3日→1週間…の間隔反復 |
| 用語辞典 | 検索・関連問題へのジャンプ |
| 模試 | 本番（100問・120分）／ハーフ（50問）／ミニ（20問）。分野別評価点と合否判定、見直し、解き直し |

続けたくなる仕組み：XPとレベル、連続学習日数、1日の目標リング、学習カレンダー、25種類のバッジ、合格予測スコア、ゲームの自己ベスト。

## ビルド

`main` に push すると GitHub Actions が

1. `tools/build_bank.py` で問題データを検証して `ITPass/Resources/bank.json` を生成
2. XcodeGen でプロジェクトを作成
3. **未署名の ipa** をビルドして Releases（`build-番号`）に添付

します。お手持ちの証明書で署名してインストールしてください。

## 問題を追加・修正する

`tools/data/` の Python ファイルを編集します（正解を先頭に書くと、選択肢の並びは自動でシャッフルされます）。

```python
Q("security", 2, "問題文", "正解", "誤答1", "誤答2", "誤答3", "解説")
T("network", "用語", "読み・正式名称", "説明")
```

誤答の解説は `tools/data/notes_*.txt` に「## 問題ID」の下へ `選択肢 :: 解説` の形で書きます。用語集にある選択肢は用語の説明が自動で入ります。解説が足りない選択肢があるとビルドが止まるので、書き漏れは起きません。

`python3 tools/build_bank.py` で検証と書き出しができます。アイコンは `tools/make_icon.py` で生成しています。

## 構成

```
ITPass/
  App/        起動・タブ・バッジ通知
  Models/     問題データ、学習記録、模試
  Store/      保存・出題ロジック（間隔反復）・バッジ
  Views/      ホーム / 学ぶ / 練習 / ゲーム / カード / 模試 / 記録
  Design/     色・共通部品
tools/        問題データとアイコンの生成スクリプト
```

iOS 17 以降 / SwiftUI / Swift Charts / 学習データは端末内に保存
